# Saved path library

This template deliberately contains only two sample `.path` files:

- `Example Mobility.path`: a simple authored-path example.
- `Example Recovery Route.path`: a route intended to demonstrate recovery with `pathfindThenFollowPath`.

Replace or delete both after game reveal. Create autonomous routines in Java under `src/main/java/frc/robot/autos/Autos.java`; do not create `.auto` files.
