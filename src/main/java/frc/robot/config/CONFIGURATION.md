# Season configuration

This folder holds values the team expects to change as the robot and game become real: controller ports, CAN topology, field poses, drivetrain calibration, vision limits, active profile, and autonomous policy.

Change a value here once, with a measured reason, rather than duplicating it in commands. After edits, build and verify the related dashboard status on the robot. For CAN or swerve changes, support the robot safely before driving.
